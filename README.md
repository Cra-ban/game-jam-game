# Sam Altman stole my RAM
Me and [@kv-na s](https://github.com/Kv-na) submission for the [Open\OST Open game jam](https://itch.io/jam/openost-open-game-jam). 

[play here](https://craban.itch.io/sam-altman-stole-my-ram)

## Controls: 

- left-click to interact

- right-click to examine

- move cursor to top edge of screen to open inventory. Click on items to use them.

## Disclaimers
Any similarities to real people or companies are entirely coincidental. 

No AI was used in the creation of this game.

All assets are created from public domain or free use photos.
